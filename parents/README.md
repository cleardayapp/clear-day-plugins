# Clear Day for Parents

Skills that help a family find and compare licensed daycare with the assistant, using public records.

## What it sends and fetches

- **One connection.** The plugin connects to a single remote server, `https://mcp.useclearday.com/mcp/find`. It makes no other network requests.
- **Data categories.** The tools on that server return public licensing and inspection records for childcare providers. They need only a location or a provider name and an age group. Do not share a child's name, birth date, photo or health details.
- **Storage.** The plugin itself stores nothing. It has no accounts, settings or local files of its own.
- **Writes.** The tools are read-only. The assistant never sends messages on your behalf.
