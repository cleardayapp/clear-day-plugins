# Clear Day for Directors

Skills that help a childcare director work through enrollment inquiries, tours and licensing questions with the assistant.

## What it sends and fetches

- **One connection.** The plugin connects to a single remote server, `https://mcp.useclearday.com/mcp`. It makes no other network requests.
- **Data categories.** The tools on that server may return public licensing records and, once you sign in to Clear Day, your own school's enrollment inquiries and tour schedule. Your questions and the tool results are shared with that server only to answer your request.
- **Storage.** The plugin itself stores nothing. It has no accounts, settings or local files of its own; anything kept is kept by Clear Day under your school's account.
- **Writes.** The assistant confirms with you before any change and never sends messages itself. The one exception is booking a tour through Clear Day, which emails the family a confirmation, so the assistant says so and waits for your yes first. Website changes are saved as drafts for you to review; only you can publish, in Clear Day.
